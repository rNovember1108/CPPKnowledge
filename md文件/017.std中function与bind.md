# std::function与std::bind

## std::function

`std::function` 是一个通用的、多态的‌函数包装器‌（Function Wrapper），它是一个‌类模板‌，其模板参数是函数的签名（返回类型和参数类型列表），位于头文件 `<functional>` 中。以前没有这个‌函数包装器的时候，我们在想定义一个回调函数指针，非常的麻烦。我们通常这样的定义：

```
typedef void (*func) (int, int); // 这里的ptr就是一个函数指针
```

而使用了 `std::function` 这个类的时候，我们可以这样使用，来替换函数指针。例如：

```
std::function<void(int, int)> func;
```

`std::function` 的实例能存储、复制及调用任何可调用 (Callable) 目标，包括函数、 `Lambda` 表达式、 `bind` 表达式或其他函数对象，还有指向成员函数指针和指向数据成员指针。

它也是对 C++ 中现有的可调用实体的一种类型安全的包裹（相对来说，函数指针的类型安全机制脆弱得多）

```
#include <iostream>
#include <functional>
using namespace std;

// 声明一个模板
typedef std::function<int(int)> Functional;

//normal function
int TestFunc(int a)
{
    return a;
}

// lambda表达式
auto lambda = [](int a) ->int { return a; };

// functor仿函数
class Functor
{
public:
    int operator() (int a)
    {
        return a;
    }
};

// 类的成员函数和类的静态成员函数
class CTest
{
public:
    int Func(int a)
    {
        return a;
    }
    static int SFunc(int a)
    {
        return a;
    }
};

int main(int argc, char* argv[])
{
    // 封装普通函数
    Functional obj = TestFunc;
    int res = obj(0);
    cout << "normal function : " << res << endl;

    // 封装lambda表达式
    obj = lambda;
    res = obj(1);
    cout << "lambda expression : " << res << endl;

    // 封装仿函数
    Functor functorObj;
    obj = functorObj;
    res = obj(2);
    cout << "functor : " << res << endl;

    // 封装类的成员函数和static成员函数
    CTest t;
    obj = std::bind(&CTest::Func, &t, std::placeholders::_1);
    res = obj(3);
    cout << "member function : " << res << endl;

    obj = CTest::SFunc;
    res = obj(4);
    cout << "static member function : " << res << endl;
    return 0;
}
```

## std::bind

可将 `std::bind` 函数看作一个通用的函数适配器（Function Adapter），它接受一个可调用对象，生成一个新的可调用对象来**适应**原对象的参数列表。`std::bind` 将可调用对象与其参数一起进行绑定，绑定后的结果可以使用 `std::function` 保存。

### std::bind的作用
- 将可调用对象和其参数绑定成一个仿函数；
- 只绑定部分参数，减少可调用对象传入的参数。

各种情况举例如下:

1. 绑定普通函数

    ```
    double my_function(double x, double y)
    {
        return x / y;
    }

    int main()
    {
        // normal function
        auto fn_half = std::bind(my_function, std::placeholders::_1, 2);
        cout << fn_half(10) << endl;
        return 0;
    }
    ```

    - `std::bind` 的第一个参数是函数名，当普通函数名作为实参传递时，会隐式转换为指向该函数的指针。因此，在 `std::bind` 中，直接使用函数名 `my_function` 和使用取地址符 `&my_function` 的效果是完全等价的。
    - `_1` 是一个占位符对象，代表绑定后生成的新可调用对象的‌第一个参数‌。当调用这个新对象时，传入的第一个实参将被替换到原函数参数列表中 `_1` 所在的位置。占位符定义在 `<functional>` 头文件中，并且位于 `std::placeholders` 命名空间下，完整写法：`std::placeholders::_1`。占位符详细见下一小节。

2. 绑定类成员变量

    ```
    struct Foo
    {
        int data = 10;
        void print_sum(int n1, int n2)
        {
            std::cout << n1 + n2 << std::endl;
        }
    };

    int main()
    {
        Foo foo;
        //auto f1 = std::bind(Foo::print_sum, &foo, 95, std::placeholders::_1);  //错误，请使用 "&" 来创建指向成员的指针
        auto f2 = std::bind(&Foo::print_sum, &foo, 95, std::placeholders::_1);
        f2(5); // 100
        return 0;
    }
    ```

    - `std::bind` 绑定类成员函数时，第一个参数表示对象的成员函数的指针，第二个参数表示对象的地址。
    - 必须显示的指定 `&Foo::print_sum`，因为编译器不会将对象的成员函数隐式转换成函数指针，所以必须在 `Foo::print_sum` 前添加 `&`；
    - 使用对象成员函数的指针时，必须要知道该指针属于哪个对象，因此第二个参数为对象的地址 `&foo` 或者通过占位符调用时传入对象；

3. 绑定一个引用参数

    默认情况下，`std::bind`的那些不是占位符的参数被拷贝到 `std::bind` 返回的可调用对象中。但是，与 `Lambda` 类似，有时对有些绑定的参数希望以引用的方式传递，或是要绑定参数的类型无法拷贝，`std::ref` 与 `std::cref`有了用武之地。

    ```
    void my_function(int x, int& y, const int& z)
    {
        std::cout << x + y + z;
    }

    int main()
    {
        int cy = 2, cz = 3;
        auto fn_half = std::bind(my_function, std::placeholders::_1, std::ref(cy), std::cref(cz));
        fn_half(10);

        return 0;
    }
    ```

### 占位符的作用

在绑定函数时"预留参数位置"，延迟到调用时再传入具体值。`std::placeholders::_1`、`std::placeholders::_2` ...... `std::placeholders::_20` 就是一个"空位标记"，调用时传入的值会填入这个空位。

1. 延迟参数传入（最常用）

    ```
    int add(int a, int b)
    {
        return a + b;
    }

    int main()
    {
        // 固定第一个参数为 10，第二个参数留空
        auto add10 = std::bind(add, 10, std::placeholders::_1);
        std::cout << add10(5) << std::endl;   // 10 + 5 = 15
        return 0;
    }
    ```

2. 调整参数顺序

    ```
    void print(int a, int b, int c)
    {
        std::cout << a << ", " << b << ", " << c << std::endl;
    }

    int main()
    {
        // 原始顺序: a, b, c
        // 绑定后顺序: c, a, b（通过占位符调整）
        auto reordered = std::bind(print, std::placeholders::_3, std::placeholders::_1, std::placeholders::_2);

        reordered(1, 2, 3);  // 输出: 3, 1, 2   // _3 → 3, _1 → 1, _2 → 2
        return 0;
    }
    ```

3. 成员函数不绑定对象（延迟传入对象）

    ```
    struct Foo
    {
        int value;
        void print() const
        {
            std::cout << value << std::endl;
        }
    };

    int main()
    {
        Foo foo1{ 10 };

        // 绑定对象(&foo1)
        auto printer1 = std::bind(&Foo::print, &foo1);
        printer1();  // 输出: 10

        // 不绑定对象，用_1表示"调用时传入对象"
        auto printer2 = std::bind(&Foo::print, std::placeholders::_1);
        printer2(&foo1);  // 输出: 10
        return 0;
    }
    ```
