# 基础数据类型

## 分类

C++ 的基础数据类型（Fundamental Types）是构建程序的基石。它们主要分为 **整数类型‌**、‌**浮点类型‌**、‌**布尔类型‌**、**字符类型‌**和**特殊类型**。

### 整数类型

用于存储整数值。根据是否有符号和占用字节数不同，分为多种。

| 类型 | 典型大小 (字节) | 取值范围 | 说明 |
| --- | --- | --- | --- |
| `short`/`short int` | 2 | -$2^{15}$ 到 $2^{15}$-1 | 节省内存，但范围小。 |
| `int` | 4 | -$2^{31}$ 到 $2^{31}$-1 | ‌最常用‌的整数类型。 |
| `long`/`long int` | 4 或 8 | 取决于平台 | 在 Windows 上通常是 4 字节，Linux 64位上是 8 字节。 |
| `long long` | 8 | -$2^{63}$ 到 $2^{63}$-1 | ‌大范围整数首选‌，保证至少 64 位。 |
| `char` | 1 | -128 到 127 | 本质是小整数，常用于存字符。有符号性取决于编译器。 |

修饰符：‌
- unsigned‌：无符号，只能存非负数，范围翻倍（如 `unsigned int` 为 0 到 $2^{32}$-1）
- signed‌：有符号（默认），可存负数。
- ‌最佳实践‌：如果需要跨平台精确控制位数，建议使用 C++11 引入的 `<cstdint>` 头文件中的固定宽度类型，如 `int32_t`, `uint64_t` 等。

#### int 和 unsigned‌ int 的差异:

| 特性 | int (有符号) | unsigned int (无符号) |
| --- | --- | --- |
| ‌二进制解释‌ | 最高位为符号位 (0正1负)，通常采用‌补码‌表示 | 所有位均表示数值大小 |
| ‌取值范围‌ (32位系统) | -$2^{31}$ 到 $2^{31}$-1 | 0 到 $2^{32}$-1 |
| ‌默认类型‌ | 字面量 123 默认为 int | 需后缀 u 或 U，如 123u |
| ‌溢出行为‌ | ‌C++ 标准未定义行为 (UB)‌ ⚠️ (编译器可任意处理，可能导致崩溃或逻辑错误，即使看似回绕，也不可依赖) | ‌定义良好的行为‌ ✅ (遵循模运算，自动回绕/截断) |
| ‌典型用途‌ | 通用计数、数学计算、可能为负的指标 | 位操作、数组索引、哈希值、纯非负计数 |

1. 混合运算时的隐式转换（最危险的坑）

    当 `int` 和 `unsigned int` 进行运算或比较时，C++ 标准规定：‌`int` 会被隐式转换为 `unsigned int‌`。这会导致极其反直觉的结果，尤其是当 `int` 为负数时。

    ```
    int a = -1;
    unsigned int b = 1;

    if (a < b)
    {
        std::cout << "Less" << std::endl;
    }
    else
    {
        std::cout << "Greater" << std::endl; // 输出这个！
    }
    ```

    直觉上：`-1 < 1`，应该输出 "Less"，实际上：`a (-1)` 被转换为 `unsigned int`，`-1` 的补码是 `0xFFFFFFFF`，作为 `unsigned` 解释为 `4,294,967,295 (UINT_MAX)`，所以: `4,294,967,295 > 1`。

2. 循环边界错误

    ```
    for (unsigned int i = 10; i >= 0; --i)
    {
        std::cout << i << std::endl;
    }
    ```

    当 `i` 为 0 时，执行 `--i`，`i` 变为 `4,294,967,295 (UINT_MAX)`，`i >= 0` 永远为 `true`，因为 `unsigned` 永远非负，会自动回绕。

3. `sizeof` 与打印

    - `sizeof(int)` 和 `sizeof(unsigned int)` 通常相同（在大多数现代平台为 4 字节）。
    - 打印时需匹配格式符（C风格）或流类型（C++风格）：

        ```
        int a = -10;
        unsigned int b = 10;

        // C++ style (安全)
        std::cout << a << ", " << b << std::endl; 

        // C style (需注意)
        printf("%d, %u\n", a, b); 
        // 如果误用: printf("%u", a); 会将 -1 打印为巨大正数
        ```


**总结**：除非你有明确理由需要使用无符号数，否则优先使用 `int`。它可以避免大多数隐式转换带来的 Bug，且符合人类对数字的直觉，尽量避免在有符号和无符号整数之间进行混合运算或比较。如果编译器发出警告，请务必重视并修复。

#### 原码补码反码

##### 定义

原码、反码、补码是‌有符号整数在计算机中的二进制编码方式‌，核心目的是让减法可以用加法来计算，简化硬件设计。

以8位有符号整数为例，最高位是‌符号位‌：0表示正数，1表示负数，剩下的位存储数值绝对值。

| 编码类型 | 正数表示 | 负数表示 |
| --- | --- | --- |
| ‌原码‌ | 符号位+绝对值二进制 | 符号位+绝对值二进制 |
| ‌反码‌ | 和原码完全相同 | 符号位不变，数值位按位取反 |
| ‌补码‌ | 和原码完全相同 | 反码+1 |

规则简化：正数的原码、反码、补码‌完全一样‌，只有负数需要转换。

##### 示例

1. 正整数 `+5`:

    ```
    原码：0 0000101 → 0x05
    反码：0 0000101 → 0x05（和原码相同）
    补码：0 0000101 → 0x05（和原码相同）
    ```

2. 负整数 `-5`：

    ```
    原码：1 0000101 → 0x85（符号位1，数值位是5的二进制）
    反码：1 1111010 → 0xFA（符号位不变，数值位0000101 → 1111010）
    补码：1 1111011 → 0xFB（反码+1）
    ```

##### 补码的意义

补码的核心优势：‌把减法统一成加法，同时解决了“零的二义性”问题‌。

1. 统一加减法

    计算 `5 - 3` 等价于 `5 + (-3)`，用补码可以直接相加得到正确结果：

    ```
     5 的补码：00000101
    -3 的补码：11111101
    相加结果：(1)00000010 → 最高位溢出舍弃，剩下00000010就是+2，结果正确
    ```

    如果用原码直接相加，符号位需要额外判断，硬件设计会复杂很多。

2. 解决零的二义性

    原码中，零有两种编码：`+0 = 00000000`，`-0 = 10000000`，浪费了一个编码位置。
    补码中，零只有一种编码 `00000000`，多出来的编码可以多表示一个最小负数：
    - 8 位补码可以表示的范围是 `‌-128 ~ +127`‌（共 256 个数，刚好占满 8 位所有编码）。
    - 原码只能表示 `-127 ~ +127`，浪费了`-0` 这个位置。

**总结**：现代计算机中，所有有符号整数都是用补码存储的‌，原码和反码只用于手动计算转换，不会直接存储。而无符号整数没有负数，也不需要符号位‌，使用原码直接存储。

### 浮点数类型

用于存储带小数点的数值，遵循 IEEE 754 标准。

| 类型 | 大小 (字节) | 有效精度 (十进制位) | 说明 |
| --- | --- | --- | --- |
| `float` | 4 | ~6-7 位 | 单精度，节省内存，适合图形学、海量数据。 |
| `double` | 8 | ~15-17 位 | ‌双精度，默认选择‌。精度高，现代 CPU 运算速度通常与 float 无异。 |

**float 与 double 的存储与精度**：

1. 核心对比

| 特性 | float (单精度) | double (双精度) |
| --- | --- | --- |
| ‌总位数‌ | ‌32 bit‌ (4 字节) | ‌64 bit‌ (8 字节) |
| ‌符号位 (Sign)‌ | 1 bit | 1 bit |
| ‌指数位 (Exponent)‌ | 8 bit | 11 bit |
| ‌尾数位 (Mantissa/Fraction)‌ | 23 bit | 52 bit |
| ‌有效数字精度‌ | 约 ‌6-7‌ 位十进制数字（保证6位） | 约 ‌15-16 位十进制数字（保证15位） |
| ‌默认字面量类型‌ | 需后缀 f (如 3.14f) | 默认 (如 3.14) |

2. 存储结构详解

    浮点数在内存中并非直接存储二进制小数，而是采用科学计数法的二进制形式：V = $(-1)^{S}$ × 1.M × $2^{E-Bias}$

    ```
    float(32位):
    ----`S` (1位)‌: 符号位。0为正，1为负。
    ----`E` (8位)‌: 指数部分。偏移量（Bias）为 ‌127‌。
    --------实际指数 = 存储值 - 127。
    --------范围：-126 到 +127（特殊值除外）。
    ----`‌M` (23位)‌: 尾数部分（小数部分）。

    double(64位)
    ----`S` (1位)‌: 符号位。
    ‌----`E` (11位)‌: 指数部分。偏移量（Bias）为 ‌1023‌。
    --------实际指数 = 存储值 - 1023。
    --------范围：-1022 到 +1023。
    ‌----`M` (52位)‌: 尾数部分。
    ```

3. 关于精度

    - 隐含前导 1：

        对于任何一个‌非零、非无穷非NaN‌的标准化数，二进制的整数部分永远是 1，不可能是别的数——这是科学计数法的规则决定的：

        ①如果你写 0.1 × 2^5，标准写法一定会调整指数变成 1.0 × 2^4，让整数部分固定为1；

        ②如果你写 10.1 × 2^3，也会调整指数变成 1.01 × 2^4，整数部分还是1。

        既然整数部分‌永远是1‌，那我们就不需要把它存在内存里了，只需要存小数部分 M，使用的时候再把这个隐含的1加上就行——这就是「隐含前导1」的来源。

    - 精度的计算

        因为我们不需要存那个固定的1，只需要存小数部分M，所以对于 `float` 实际有效位数是 23位尾数 + 1个隐含的前导1 = 总共24位二进制精度，`double`总共 52 + 1 = 53 位。我们把二进制精度转换成十进制精度，就能得到我们常说的有效位数：

        十进制有效位数 ≈ 二进制精度×$\log_{10}(2)$ ≈ 二进制精度 × 0.3010

        ①对于 `float`：24 × 0.3010 ≈ 7.22，所以说 `float` 精度是6-7位十进制有效数字，7.2‌2 是‌平均能力‌，6‌ 是‌底线‌（`std::numeric_limits<float>::Digits10()`，保证不出错），7‌ 是‌常态‌（**大多数时候**你能用到 7 位），8‌ 是‌禁区‌（基本不可信）。

        ②对于 `double`：53 × 0.3010 ≈ 15.95，所以说float精度是15-16位十进制有效数字，15.95‌ 是‌平均能力‌，15‌ 是‌底线‌（`std::numeric_limits<double>::Digits10()`，保证不出错），16 是常态（**绝大多数时候**都准），17‌ 是唯一标识‌‌（`std::numeric_limits<double>::max_digits10()` 用于打印输出的往返转换需求，不改变本身精度位数的定义）。

### 布尔类型
- ‌类型‌：`bool`
- ‌大小‌：通常为 1 字节（虽然理论上只需 1 位，但为了地址对齐通常占 1 字节）。
- ‌值‌：`true` (内部通常为 1) 和 `false` (内部为 0)。
- ‌用途‌：逻辑判断、条件控制。

### 字符类型

用于存储单个字符，本质也是整数（ASCII 码或 Unicode 码点）。

| 类型 | 大小 | 说明 |
| --- | --- | --- |
| `unsigned char` | 1 | 明确无符号，范围 0~255。‌常用于处理原始字节数据‌。 |
| `signed char` | 1 | 明确有符号，范围 -128~127。 |
| `char` | 1 | 基础字符类型。可能是 `signed` 或 `unsigned`，‌行为不确定‌，由编译器定义。 |
| `wchar_t` | 2 或 4 | 宽字符，用于 Unicode (Windows 上通常是 UTF-16, Linux 上是 UTF-32)。 |
| `char16_t` | 2 | UTF-16 字符 (C++11)。 |
| `char32_t` | 4 | UTF-32 字符 (C++11)。 |

### 特殊类型

- 含义‌：`void` 表示“无类型”。
- ‌用途‌：
    - 函数不返回值：`void func()`;
    - 指针指向未知类型：`void* ptr;` (通用指针，需强制转换后使用)。
    - 函数无参数：`int func(void);` (C 风格，C++ 中可省略 void)。
