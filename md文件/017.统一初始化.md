# 统一初始化

统一初始化是 C++11 引入的核心特性，目标是用一套 `{}` 语法初始化几乎所有类型（包括基础类型、聚合类型、自定义类类型等），同时解决旧语法的一些问题。但它也带来了新的坑，实际使用需要理解其规则。

C++ 初始化简单分为：

- 直接初始化：`int a(4);` 或 `int a{4};`
- 拷贝初始化：`int a = 4;`
- 值初始化：`int a{};` → 零值
- 默认初始化：`int a;` → 局部变量未初始化

## 目的与作用

1. 统一初始化的语法

    在 C++11 之前，初始化对象时需要使用不同的语法，例如：

    ```cpp
    int a = 10;                 // 拷贝初始化
    int* p = new int(42);       // new表达式
    double b(3.14);             // 直接初始化
    std::string s = "hello";    // 字符串初始化
    int arr[] = {1, 2, 3};      // 数组初始化
    std::vector<int> v;         // 容器默认构造（无元素），需要 push_back 才能填入元素
    ```

    C++11 通过引入的 `{}` 语法实现统一初始化方法：

    ```cpp
    int a{10};
    int* p = new int{42};
    double b{3.14};
    std::string s{"hello"};
    int arr[]{1, 2, 3};
    int* arr_ptr = new int[3]{1, 2, 3};
    std::vector<int> v{1, 2, 3};
    ```

2. 聚合类型支持花括号初始化

    ```cpp
    struct Point { int x; int y; };
    Point p1 = {1, 2}; // C++11 之前必须有 =，不能省略
    Point p2{1, 2}; // C++11 起，合法
    ```

    在 C++11 之前，聚合类型的初始化只能使用 `=` 加上 `{}`，而 C++11 之后可以直接使用 `{}`。

3. 类类型支持花括号初始化

   在 C++11 之后，类类型可以用 `{}` 调用任意构造函数。如果类同时提供了 `std::initializer_list` 构造函数，非空 `{}` 会优先匹配它。

    ```cpp
    class MyClass
    {
    public:
        MyClass(std::initializer_list<int> vals)
        {
            vec = vals;
        }
    private:
        std::vector<int> vec;
    };

    MyClass obj{1, 2, 3}; // 初始化
    ```

4. 函数的可变参数，用统一初始化语法初始化形参

    ```cpp
    void print(std::initializer_list<int> vals)
    {
        for (int v : vals)
        {
            std::cout << v << " ";
        }
    }

    print({1, 2, 3, 4});  // 输出 1 2 3 4
    ```

    实参 `{}` 以统一初始化的方式初始化了形参 `vals`。这是实现可变参数的关键手段。

5. 配合范围 `for` 循环，用统一初始化语法初始化循环变量

    ```cpp
    for(int v : {1, 2, 3, 4})
    {
        std::cout << v << " ";
    }
    ```

6. 默认值初始化的简洁与安全使用

    `{}` 不带参数时，将对象初始化为零/默认值。

    ```cpp
    int a{};          // 0
    double d{};       // 0.0
    std::string s{};  // 空字符串
    MyClass obj{};    // 调用默认构造
    ```

    这比 `int a = 0;` 更简洁。

7. 禁止窄化转换

    `{}` 在编译期阻止精度丢失，而 `()` 不阻止，适用于浮点转整数、长整型转短整型、有符号转无符号、双精度转单精度等场景：

    ```cpp
    int a = 3.14;    // warning，a = 3
    int b(3.14);     // warning，b = 3
    int c{3.14};     // error，窄化转换
    ```

    `a` 和 `b` 在编译时只是警告，而 `c` 会直接报错，这是统一初始化最重要的安全优势。这个检查是编译期的，不生成任何运行时指令。编译器在语义分析阶段就报错，不会生成代码。

8. 避免 `()` 的解析问题

    `()` 在空参数时会被解析为函数声明，而 `{}` 则不会。

    ```cpp
    std::vector<int> v1();   // 声明了一个函数！不是对象
    std::vector<int> v2{};   // 空 vector 对象
    ```

## 底层机制

### 基础类型（直接初始化）

对于 `int`、`double`、`char` 这类基础类型，`{}` 初始化的底层机制和类类型完全不同，没有构造函数调用，没有 `std::initializer_list`，编译器直接生成赋值或置零的指令。核心情况分为两种：

1. `{}` 里有值

    ```cpp
    int a = 4;
    int b(4);
    int c{4};
    ```

    编译器直接把它当作直接初始化处理，生成一条把常量写入变量的指令。和 `int a = 4;`、`int b(4);` 在底层完全等价，没有任何额外开销。汇编代码一致：

    ![](..\images\15fbf31cb56c4b2b8228e029fd821c19.png)

2. `{}` 为空

    ```cpp
    int a{};
    int b;
    ```

    这是值初始化，编译器保证变量被置为零值或默认值（`int` 为 0，`double` 为 0.0，指针为 `nullptr`，`char` 为 `\0`），但是这和 `int b;` 有着关键的区别。对于局部变量，`int b;` 不生成任何初始化指令，`b` 的值取决于栈上残留的数据。`int a{};` 会生成一条置零指令（通常是 `mov 0`）。汇编代码如下：

    ![](..\images\665a545c9bc740f1b04a6bd90dcb18ac.png)

    这是 `{}` 初始化对基础类型最实际的价值：保证零初始化，避免未定义行为。

### 聚合类型（聚合初始化）

在 C++11 之前，聚合类型只能用带 `=` 的花括号初始化，`{}` 初始化列表只被允许出现在拷贝初始化的语境里，即必须有 `=`。C++11 引入了列表初始化，把 `{}` 提升为一等公民，才允许它出现在直接初始化的位置。`{}` 会执行**聚合初始化**，编译器不会调用构造函数，而是直接按照成员在类中声明的顺序，用 `{}` 里的元素逐个拷贝初始化对应的数据成员。上面提到的 `struct Point { int x; int y; };` 和数组（Array）等都是聚合类型。

**注意：C++11 中聚合类型需满足：无用户提供的构造函数、无私有/保护的非静态数据成员、无基类、无虚函数。**

### 类类型（构造函数重载决议）

对于非聚合的类类型，`{}` 会触发构造函数调用。但决议顺序需要区分**空初始化列表**和**非空初始化列表**两种情况：

#### 非空初始化列表

非空 `{}` 的决议顺序有特殊的两阶段规则：
1. 优先：只考虑 `std::initializer_list` 构造函数。如果类有 `std::initializer_list` 构造函数且实参能匹配，强制选择它，即使其他构造函数可能更匹配。
2. 兜底：如果第一阶段找不到可行的 `std::initializer_list` 构造函数，才考虑类的所有其他构造函数，并将 `{}` 内的元素作为独立的实参进行常规重载决议。

当一个类同时有 `std::initializer_list` 构造函数和其他构造函数时，非空 `{}` 会优先匹配 `std::initializer_list` 版本，例如标准库中的 `std::vector`：

```cpp
std::vector<int> v1(10, 0);   // 10 个 0
std::vector<int> v2{10, 0};   // 两个元素：10 和 0
```

`v2` 调用的是 `std::initializer_list<int>` 构造函数，而不是 `(size, value)` 版本。这是统一初始化语法最著名的坑之一。

#### 空初始化列表

空 `{}` 有一个**优先级更高**的特殊规则，排在两阶段决议之前：当类同时提供了默认构造函数和 `std::initializer_list` 构造函数时，空 `{}` **优先调用默认构造函数**，而非匹配空的 `std::initializer_list`。

```cpp
class MyClass
{
public:
    MyClass()
    {
        std::cout << "默认构造" << std::endl;
    }

    MyClass(std::initializer_list<int>)
    {
        std::cout << "initializer_list 构造" << std::endl;
    }
};

MyClass obj1;       // 默认构造
MyClass obj2{};     // 默认构造，直接列表初始化
MyClass obj3 = {};  // 默认构造，拷贝列表初始化，同样不会走空 initializer_list 版本
MyClass obj4{1, 2}; // initializer_list 构造
```

这条规则是 C++ 标准特意设计的，目的是让 `{}` 保持"零值初始化"的直觉语义，避免空列表意外匹配到 `initializer_list` 构造函数。只有当类**没有默认构造函数**时，空 `{}` 才会匹配到 `initializer_list` 版本（空列表）。

#### `explicit` 构造函数

`explicit` 构造函数在拷贝列表初始化语境中不可用，但在直接列表初始化中可用。拷贝初始化的语义是**隐式转换**，编译器需要把右边的值转换成左边的类型。`explicit` 的作用就是禁止这种隐式转换，要求用户显式写出类型。除了普通构造函数，`std::initializer_list` 构造函数也受这一条约束。

```cpp
class MyClass
{
public:
    explicit MyClass(std::initializer_list<int> vals)
    {
        vec = vals;
    }
private:
    std::vector<int> vec;
};

MyClass obj1 = {1,2}; // 编译错误！拷贝列表初始化无法使用 explicit 构造函数
MyClass obj2{1,2};
```

#### 非静态数据成员初始化

在 C++11 起，非静态数据成员也可以用 `{}` 进行默认初始化。例如：

```cpp
class MyClass
{
public:
    int count{0}; // C++11 起合法
    std::string name{"test"}; // C++11 起合法
};
```

### 函数调用中的初始化列表实参（拷贝列表初始化）

#### 使用 `{}` 初始化 `std::initializer_list` 形参

`{}` 作为实参，用于拷贝列表初始化形参，这是统一初始化语法的一种形式。不是形参自己做了统一初始化，而是实参 `{}` 以统一初始化的方式初始化了形参。`std::initializer_list` 是目标类型，`{}` 去初始化它，触发编译器生成底层数组 + 构造 `std::initializer_list` 视图。这是统一初始化在多值路径上的典型表现。

```cpp
void print(std::initializer_list<int> nums) {}
print({1, 2, 3});
```

#### 函数重载中的 `{}` 实参优先级

当函数有多个重载版本时，`{}` 实参会优先匹配 `std::initializer_list` 形参的版本，而不是将花括号内的元素作为独立实参去匹配其他重载。这条规则和类构造函数的两阶段决议是平行的。

```cpp
void bar(int a, int b);                        // 重载 1：两个 int 参数
void bar(std::initializer_list<int> il);       // 重载 2：initializer_list 参数

bar(1, 2);        // 匹配重载 1：两个独立 int
bar({1, 2});      // 匹配重载 2：initializer_list 优先
bar({1});         // 匹配重载 2：即使只有一个元素，也优先 initializer_list
bar({});          // 匹配重载 2：空列表同样匹配 initializer_list
```

注意最后一行 `bar({})`——空 `{}` 作为函数实参时，只要存在 `initializer_list` 形参的重载，就会优先匹配它。这点和类构造函数的空 `{}` 规则不同（类构造函数空 `{}` 优先默认构造函数），需要区分：
- **类定义**：`MyClass obj{};` → 有默认构造则优先默认构造。
- **函数实参**：`bar({});` → 优先匹配 `initializer_list` 形参。

## 注意事项

使用 `std::initializer_list` 有几点需要注意：
1. `std::initializer_list` 的元素是 `const` 的，不能通过它修改值

    ```cpp
    void print(std::initializer_list<int> vals)
    {
        // *vals.begin() = 10;  // 编译错误，不能给常量赋值
    }
    ```

2. 按值传递开销很小，`std::initializer_list` 内部就是一个指针加一个 `size`，拷贝它只复制这两个字段，不会复制底层元素。

3. `std::initializer_list` 的拷贝是浅拷贝，只拷贝指针和长度，不拷贝元素。底层数组的生命周期仅限于**包含该初始化列表的完整表达式**，完整表达式结束后数组即销毁，与 `std::initializer_list` 对象本身的生命周期无关。底层数组在函数返回后失效，返回它会导致悬空引用。

    ```cpp
    std::initializer_list<int> bad()
    {
        auto il = { 1, 2, 3 }; // 完整表达式已结束，底层数组已销毁
        return il; // 危险，il 指向已销毁的数组 — 悬空指针！
    }
    ```

4. 不要长期持有 `std::initializer_list` 的副本（无论值、引用还是指针），底层数组可能已销毁。如果要保存元素，立即拷贝到自己的容器里。

    ```cpp
    class Bad
    {
        std::initializer_list<int> a;  // 危险
    public:
        Bad(std::initializer_list<int> l) : a(l) {}
        // a 指向的数组可能已经销毁
    };
    ```

## 总结

统一初始化是 C++11 引入的一套用 `{}` 初始化所有类型的语法目标，而 `std::initializer_list` 是让这套语法能够承载多个值的关键支撑类型。换句话说，`std::initializer_list` 是统一初始化在容器/多值场景下的底层机制，但统一初始化本身不限于 `std::initializer_list`。
