# 显示缺省函数（=default）与显示删除函数（=delete）

## 显式缺省函数（=default）

在 C++ 中，声明自定义的类型( `class A` )之后，编译器会默认生成一些成员函数，这些函数被称为**类的默认函数**，如默认构造函数、默认拷贝构造函数、默认拷贝赋值运算符函数、默认移动构造函数、默认移动赋值运算符函数、默认析构函数。

C++11 允许添加 `=default` 说明符到这些函数声明的末尾，以将该函数声明为显示缺省函数。这就使得编译器为显示缺省函数生成了默认实现，它比手动编程函数更加有效。

例如，每当我们声明一个有参构造函数时，编译器就不会创建默认的无参构造函数。在这种情况下，我们可以使用 `=default` 说明符来创建默认构造函数。以下代码演示了如何创建：

```
#include <iostream>
using namespace std;

class Test
{
public:
    Test() = default;  // 显式指定缺省函数 (补充默认构造函数)
    Test(int i) : data(i) {}

private:
    int data;
};

int main()
{
    Test test;
    return 0;
}
```

显示缺省函数（`=default`）仅适用于特殊的成员函数‌，且该函数‌不能包含默认参数。例如，以下代码解释了非特殊成员函数和包含参数的构造函数不能显式缺省：

```
class B
{
public: 
    // Error, func is not a special member function. 
    int func() = default;

    // Error, constructor B(int, int) is not a special member function.
    B(int, int) = default;

    // Error, constructor B(int=0) has a default argument.
    B(int = 0) = default;
};
```

显示缺省函数（`=default`） 能在类外的定义中修饰特殊成员函数, 配合条件编译能够为一个类实现多个函数版本（比如：一个显示缺省版本，一个自定义版本），但需要注意只能二选一，否则违反 ODR（单一定义规则），将报错。甚至你还可以把定义放到不同的两个 CPP 文件，配合条件编译选择不同的文件参与编译。但是不建议这样做，可以通过使用‌继承、多态、策略模式或工厂模式‌来实现不同版本的行为切换，确保每个类在其定义范围内遵守单一定义规则。

```
class Example
{
public:
    Example() = default;
    Example(const Example&);

private:
    int data;
};

#ifdef USE_DEFAULT_IMPL
    //版本A:类外使用
    Example::Example(const Example& ex) = default;
#else
    // 版本 B：自定义实现
    Example::Example(const Example& ex)
    {
        // 自定义逻辑
    }
#endif
```

当然我们也可以使用 `{}` 来实现空的函数体，那为什么 C++ 还要提出使用 `=default` 呢？尽管两者可能表现相同，但使用 `=default` 而不是使用 `{}` 仍然有一定的好处。以下几点做了一定的解释:
1. 用户定义的默认函数，即使它什么也不做，使用 `{}`，也会使得类型不是聚合类型，也不是平凡类型。如果您希望您的类是聚合类型或平凡类型（或通过传递性，POD 类型），那么需要使用 `=default`。
2. 对于拷贝/移动构造函数、拷贝/移动赋值运算符函数，手动写 `{}` 通常是‌严重错误‌，因为它不会拷贝/移动任何数据，导致新对象包含垃圾值或未初始化的内存。而 `=default` 会正确执行深拷贝或浅拷贝（取决于成员类型）。
3. 在类声明中统一使用 `=default` 语法，是现代 C++ 推荐的最佳实践，它使代码更简洁、更安全、更高效。


## 显式删除函数（=delete）

在 C++11 之前，操作符 `delete` 只有一个目的，即释放已动态分配的内存。而 C++11 标准引入了此操作符的另一种用法，即用于显式禁止编译器生成或用户调用特定的函数。这是通过 `=delete` 来完成的。将函数标记为删除后，任何尝试调用该函数的代码都会导致‌编译错误‌。`=delete` 不只限于成员函数，也可以是普通函数。

**禁用函数**：

```
class Test
{
public:
    Test() = default;  // 显式指定缺省函数
    Test(int i) : data(i) {}
    Test(const Test& t) = delete; // 显式删除拷贝构造函数

private:
    int data;
};

void g_test() = delete;  // 显式删除函数

int main()
{
    g_test();  // 全局函数，尝试引用已删除的函数，无法通过编译
    Test obj1;
    Test obj2(obj1); // 成员函数，尝试引用已删除的函数，无法通过编译
    return 0;
}
```

**禁用不需要的参数转换**：

```
class Test
{
public:
    Test(int) {};

    // 将double入参的构造函数声明为显示删除函数。
    // 若没有此定义，即使A(double)未定义，
    // A(int)仍会接受任何double值作为参数并将其隐式转换为int
    Test(double) = delete;
};
int main()
{
    Test obj1(1);

    // 错误，从double类型到类Test的构造已被显示删除
    Test obj2(100.1);
    return 0;
}
```

显式删除函数的定义（即 `=delete`）必须出现在函数的‌第一个声明‌中。这是为了防止用户意外调用一个后来才被删除的函数。换句话说，以下方法是将函数声明为显示删除的正确方法：

```
class Test
{
public:
    Test() = delete;
};
```

但是以下尝试声明删除函数的方法会产生错误：

```
class Test
{
public:
    Test();
}; 

// 错误, 只能在第一个声明中删除函数
Test::Test() = delete;
```

为什么 `=default` 能够在类外定义而 `=delete` 不可以？
- `=delete` 是一种‌否定性‌操作，它告诉编译器“这个函数不存在/不可用”。标准规定，为了尽早捕获错误，`=delete` 应尽可能早地出现（即在第一个声明中）。
- `=default` 是一种‌肯定性‌操作，它告诉编译器“请使用默认逻辑实现这个函数”。这更像是一个普通的函数定义，只是内容由编译器生成。因此，它遵循普通成员函数的“声明-定义”分离规则，允许在类外定义。

最后，显式删除函数有什么好处？
- 删除特殊成员函数提供了一种更简洁的方法来防止编译器生成我们不想要的特殊成员函数。（如“禁用函数”示例中所示）。
- 删除正常成员函数或非成员函数可防止有问题的类型导致调用非预期函数（如“禁用不需要的参数转换”示例中所示）。

**注意**：
1. `=default` 只能用于 6 个特殊的类成员函数。
    - ‌默认构造函数‌ (Default constructor)
    - 默认‌拷贝构造函数‌ (Copy constructor)
    - 默认‌拷贝赋值运算符‌ (Copy assignment operator)
    - 默认‌移动构造函数‌ (Move constructor, C++11 引入)
    - ‌默认移动赋值运算符‌ (Move assignment operator, C++11 引入)
    - 默认‌析构函数‌ (Destructor)

2. `=delete` 可用于任何函数‌，包括全局函数、静态成员函数、普通成员函数以及特殊成员函数。
